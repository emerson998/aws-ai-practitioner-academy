# AWS AI Practitioner Academy

Plataforma educacional independente para a certificação **AWS Certified AI Practitioner (AIF-C01)**.

## Recursos

- Idiomas: português (padrão), inglês e espanhol
- Cinco domínios com aulas e materiais de estudo
- Banco inicial de 20 questões de prática (sem repetição na prova)
- Exercícios por fase, questionário rápido, simulado e avaliação comentada
- Cronômetro, indicadores de progresso e revisão por domínio
- Preferências e progresso salvos no localStorage do navegador

**Limitação importante:** o banco inicial contém apenas 20 perguntas únicas. A opção de simulado completo apresenta essas 20 perguntas, **não** uma prova oficial de 65 itens. A aprovação exibida é uma referência interna de 70%, não equivale à pontuação escalonada AWS de 700/1000.

## Executar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Vercel

Importe este repositório em https://vercel.com/new, selecione Vite, e implante. O arquivo `vercel.json` define build e SPA rewrites.
