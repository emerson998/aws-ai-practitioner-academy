# AWS AI Practitioner Academy
Plataforma independente de estudos para **AWS Certified AI Practitioner (AIF-C01)**, com explicações originais, referências diretas à documentação oficial AWS e prática interativa no navegador.

## Funcionalidades
- Cinco domínios no formato do guia AIF-C01 (20%, 24%, 28%, 14%, 14%).
- 14 aulas originais com explicações, exemplos, pontos-chave e links oficiais por assunto.
- 30 perguntas autorais de prática com feedback imediato, explicação e referência AWS.
- Treino por domínio, treino rápido de 10 perguntas e treino de 30 perguntas com cronômetro.
- Relatório de acertos, análise por domínio, histórico de resultados e revisão comentada.
- Português (padrão), inglês e espanhol para lições, perguntas e interface.
- Progresso das aulas e histórico armazenados no navegador (localStorage).
- Layout responsivo e pronto para Vercel.

## Executar
```bash
npm install
npm run dev
npm run build
```

A plataforma não é afiliada, patrocinada ou endossada pela Amazon Web Services. Nenhum conteúdo extenso protegido da AWS foi reproduzido.

**Simulados:** este banco inicial tem 30 questões únicas; o modo geral usa 30, não as 65 questões do exame real. O limiar de 70% (se adotado como referência de treino) não equivale à escala oficial da AWS (700/1000). O exame real usa pontuação escalonada.
